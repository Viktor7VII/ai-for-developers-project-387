# Модель записи: сущности, связи, обязательные поля

Type: grilling
Status: resolved
Blocked by: 02

## Question

Какие данные хранит запись и как она связана с типом встречи: ссылка на тип или снимок его данных (название, длительность) на момент записи? Какие данные гостя обязательны и как они проверяются? Какие статусы есть у записи (только подтверждена или также отменена)?

## Текущее состояние

Запись ссылается на тип встречи; поля: имя и email гостя, начало, конец, статус (только CONFIRMED), время создания. Отмены нет.

## Answer

Решено в интервью (grilling), 2026-11-23.

1. **Отмены нет — вариант (a).** Ни гость (тикет «Роли и доступ»), ни владелец не отменяют запись. Единственный статус — «подтверждена»; запись бессрочна и всегда занимает своё время.
2. **Название в старых записях — вариант (a).** Запись ссылается на тип встречи; в кабинете показываются текущие название и описание типа. Снимка данных типа на момент записи нет.

Технические решения и следствия (приняты без отдельного обсуждения):

- Данные записи: тип встречи (обязательная связь), имя гостя, email гостя, начало, конец, статус, время создания.
- Конец хранится явно и равен началу плюс длительность на момент записи, поэтому изменение длительности типа запись не меняет (тикет «Типы встреч»).
- Имя гостя: обязательно, 1–200 символов, пробелы по краям обрезаются, пустое не принимается. Email гостя: обязателен, до 320 символов, формат `x@y.z`, пробелы по краям обрезаются.
- Один и тот же гость может создавать сколько угодно записей; уникальности по email нет.
- Связь с типом встречи никогда не обрывается: удаление типа с записями запрещено (тикет «Типы встреч»).
- Время создания фиксируется сервером с точностью до миллисекунд.

Расхождений с текущей реализацией нет. Открытые вопросы: нет. Словарь не менялся: определение «Запись» (подтверждённая встреча) решениям соответствует.
