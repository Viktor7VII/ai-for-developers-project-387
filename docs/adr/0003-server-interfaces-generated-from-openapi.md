# Серверные интерфейсы и DTO генерируются из OpenAPI

Контракт пишется на TypeSpec (`contracts/main.tsp`), из него генерируется OpenAPI, а из OpenAPI — и TypeScript SDK фронтенда, и серверные интерфейсы контроллеров и DTO для Spring Boot 4 (OpenAPI Generator 7.27, генератор `spring`, `interfaceOnly`). Контроллеры вручную реализуют сгенерированные интерфейсы, бизнес-логика остаётся в ручном коде. Так расхождение сигнатур API и контракта ломает компиляцию, а не обнаруживается в рантайме.

## Considered Options

- Ручной серверный код с проверкой расхождения (springdoc + oasdiff) — ловит и семантику, но даёт шумные диффы и тянет runtime-зависимость.
- Нативный Java-серверный эмиттер TypeSpec — не существует.

## Consequences

- Поддержка Spring Boot 4 / Jackson 3 в генераторе появилась недавно (7.20), поэтому версия генератора закреплена и обновляется осознанно.
- Компиляция ловит только сигнатуры; коды ответов и правила проверяются тестами.
- Ручные DTO заменяются сгенерированными; доменные сущности и сервисы не зависят от сгенерированных классов.
