# Календарь звонков

Сервис, в котором владелец публикует типы встреч и своё расписание, а гости без регистрации записываются на свободное время.

## Участники

**Владелец**:
Единственный человек, который проводит встречи: настраивает типы встреч и расписание и видит все записи.
_Avoid_: администратор, хост, организатор, пользователь

**Гость**:
Человек, который записывается на встречу к владельцу без регистрации, указывая имя и email.
_Avoid_: посетитель, клиент, участник, пользователь

## Встречи

**Тип встречи**:
Шаблон встречи с названием, описанием и длительностью, на который записываются гости.
_Avoid_: событие, услуга, event type

**Ссылка для записи**:
Публичный адрес страницы типа встречи, который владелец отправляет гостю.
_Avoid_: инвайт, приглашение, публичная ссылка

**Расписание**:
Недельные интервалы доступности владельца в его часовом поясе.
_Avoid_: график, рабочие часы, availability

**Слот**:
Конкретный свободный промежуток длиной в тип встречи, на который гость может записаться.
_Avoid_: окно, таймслот, свободное время

**Окно записи**:
Период из 14 календарных дней по времени владельца, начиная с сегодняшнего дня, в котором гость может выбрать слот.
_Avoid_: горизонт записи, период бронирования, доступный период

**Запись**:
Подтверждённая встреча гостя с владельцем на конкретное время по выбранному типу встречи.
_Avoid_: бронирование, бронь, встреча, событие

**Заметка**:
Текст владельца к записи, например тема разговора или договорённости; у записи не больше одной заметки, гостю она не видна.
_Avoid_: комментарий, примечание, описание записи
