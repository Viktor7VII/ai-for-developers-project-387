# Типы встреч: операции и данные

Type: grilling
Status: resolved
Blocked by: —

## Question

Какие операции с типом встречи входят в спецификацию (создание, просмотр, редактирование, удаление или архив)? Какие поля обязательны и какие у них ограничения (название, описание, длительность — допустимые значения; ссылка для записи — формат и уникальность)? Что происходит с будущими записями при изменении или удалении типа встречи?

## Текущее состояние

Создание, список, просмотр, редактирование; удаления нет. Поля: slug (уникален, `a-z0-9-`), название, необязательное описание, длительность 5–720 минут.

## Answer

Решено в интервью (grilling), 2026-11-23.

1. **Удаление — вариант (b).** Тип встречи можно удалить, только если с ним не связано ни одной записи, ни будущей, ни прошедшей. Если записи есть, удаление запрещено; записи и история сохраняются. Архивирование не добавляется.
   - Последствия: тип встречи, по которому уже были записи, остаётся в системе и виден гостям на главной; скрыть его нельзя (архива нет). Удаление — новая операция кабинета; отказ при наличии записей — отдельный случай ошибки (код и формат решает тикет «API-контракт: ошибки»).
   - Расхождение с текущей реализацией: удаления сейчас нет.
2. **Редактирование — вариант (a).** Все поля типа встречи можно редактировать в любое время, в том числе при наличии записей.
   - Изменение длительности влияет только на новые слоты; созданные записи сохраняют точные начало и конец.
   - Изменение ссылки для записи делает старую ссылку недействительной; владелец сам распространяет новую.
   - Отображение названия и описания в уже созданных записях решает тикет «Модель записи».
   - Расхождений с текущей реализацией нет.
3. **Обязательные поля и ограничения — вариант (a), без изменений.**
   - Название: обязательно, 1–200 символов, пробелы по краям обрезаются, пустое не принимается.
   - Ссылка для записи: обязательна, 1–100 символов, строчные латинские буквы, цифры и одиночные дефисы между ними; уникальна среди типов встреч.
   - Описание: необязательно, до 2000 символов; пустое означает «нет описания».
   - Длительность: обязательна, любое целое число минут от 5 до 720 включительно, без требования кратности.
   - Связь длительности с шагом слотов решает тикет «Модель слотов». Расхождений с текущей реализацией нет.

Следствия (подтверждены, не отдельные решения):

- Старая ссылка для записи после её смены или удаления типа встречи не перенаправляется; гость видит «Встреча не найдена».
- При одновременном удалении типа встречи и создании записи по нему сохраняется целостность: либо запись создаётся, а удаление отклоняется, либо удаление проходит, а создание записи отклоняется. Запись без существующего типа встречи невозможна.
- Если после изменения длительности выбранный гостем слот больше не существует, создание записи отклоняется как «слот недоступен».
- Техническое обеспечение этих гарантий решают тикеты «Конфликты» и «API-контракт: ошибки».

Итог по операциям владельца: создание, просмотр (список и отдельный тип), редактирование всех полей, удаление при отсутствии записей. Гостю типы встреч доступны только на чтение (тикет «Роли и доступ»).

Расхождение с текущей реализацией: одно — нет операции удаления.

Открытые вопросы: нет. Словарь не менялся: новых терминов нет (архив не вводится), определение «Тип встречи» решениям соответствует.
