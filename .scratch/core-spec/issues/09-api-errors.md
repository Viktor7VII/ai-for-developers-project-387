# API-контракт: ошибки валидации и конфликты записи

Type: grilling
Status: resolved
Blocked by: 07, 08

## Question

Какие коды и формат ответов у ошибок: валидация (400 или 422), не найдено (404), конфликт записи (409)? Нужны ли машиночитаемые коды ошибок и ошибки по полям, или достаточно текстового сообщения?

## Текущее состояние

Единый формат `{ message }`; 400 — валидация и некорректные параметры; 404; 409 — занятый или недоступный слот и дубликат slug.

## Answer

Решено 2026-11-23 в рамках тикета [API-контракт: эндпоинты, запросы и успешные ответы](08-api-endpoints.md), раздел «Ошибки»: единый формат `{ message }`, 400 — валидация, 404 — не найдено, 409 — слот недоступен, занятая ссылка для записи, удаление типа с записями; совпадает с текущей реализацией.
